# AGENTS.md

## Cursor Cloud specific instructions

Resilience Maps is a **frontend-only** React 19 + TypeScript + Vite PWA (MapLibre
GL, PMTiles, optional Supabase). There is no backend service to run — the app
falls back to bundled demo facilities (`public/data/demo-facilities.json`) and an
online OpenStreetMap basemap when PMTiles/Supabase env vars are unset.

- Node 22 and `npm ci` (see `package.json`) are all that's needed. The startup
  update script already installs dependencies.
- Env: copy `.env.example` to `.env.local`. All `VITE_*` values are optional for
  local dev; leaving Supabase/PMTiles blank triggers the demo-data + OSM
  fallback, which is enough to exercise the full Explore UI.
- Commands (defined in `package.json`): `npm run dev` (Vite dev server on
  `http://localhost:5173/`), `npm run lint`, `npm test` (vitest), `npm run build`
  (`tsc -b && vite build`), `npm run preview`.
- The PWA service worker is disabled in dev (`devOptions.enabled: false` in
  `vite.config.ts`); it is only generated by `npm run build`. Don't expect
  offline caching behavior when running `npm run dev`.
- The Docker/`docker-compose.yml` path builds a production static bundle served
  by nginx on port 8080 and mounts prebuilt PMTiles archives; it is for
  deployment, not local development.
